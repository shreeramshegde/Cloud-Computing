How this website works

Enterprise Serverless Cloud Architecture

This entire portfolio runs without a single virtual server (zero EC2). Here is how 14 native AWS services coordinate seamlessly:

⚡

Global CDN & Edge Delivery

Amazon CloudFront & OAC

Caches web files across 450+ Points of Presence globally with TLS 1.3 HTTPS encryption. Direct S3 access is blocked using Origin Access Control.

📦

Hardened Object Storage

Amazon S3 (Private Bucket)

Stores static assets (HTML/CSS/JS) with Block All Public Access enabled. Accessible strictly when requested by CloudFront's service principal.

⚙️

Serverless Compute & APIs

AWS Lambda & API Gateway

Event-driven Python 3.12 microservices triggered by HTTP API routes to atomically update page visits and validate contact form submissions.

🗄️

Serverless NoSQL Storage

Amazon DynamoDB

On-demand NoSQL database executing single-digit millisecond atomic counter increments and persisting message inquiries safely.

📬

Instant Event Notification

Amazon SNS (Simple Notification Service)

Publishes instant email notifications to the administrator whenever a user submits an inquiry via the portfolio contact form.

🔄

DevOps & Continuous Delivery

CodePipeline & CodeBuild

Detects git commits, validates code, uploads to S3, and invalidates CloudFront edge caches in under 60 seconds.
